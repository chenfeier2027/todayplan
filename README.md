木予 · 每日计划
一个简约治愈风格的本地每日计划网页工具所有数据保存在浏览器本地，无需后端、无需服务器。
功能特性
今日任务管理：新建、编辑、删除任务，支持置顶、计划时间、紧急程度标记
任务完成状态标记，自动统计今日完成度环形进度
每日重复任务：设置习惯任务，每天自动生成
每日复盘：记录一天完成情况，写下当日感想，保存历史复盘记录
未完成归档：查看过去日期没有做完的任务
完整响应式：适配电脑、手机移动端
复古柔和米棕配色，简洁舒适 UI

重要：全部数据存储在浏览器 LocalStorage，清除浏览器缓存会丢失数据，请记得定期导出备份。

使用方式：
方式1：直接本地打开
（1） 把 `每日计划.html` 下载到你的电脑
（2）双击用浏览器打开即可直接使用，不需要部署，不需要联网
方式2：GitHub Pages 在线访问
（1）将本仓库开启 GitHub Pages，选择从 main 分支部署
（2）访问分配的在线链接，就可以直接在浏览器网页使用
（3）在线使用数据依旧保存在你自己浏览器，不会上传到服务器。

项目说明
技术：原生 HTML + CSS + JavaScript，无任何第三方框架依赖
无数据库，无后端接口，纯客户端应用
图标全部内置 SVG，不需要额外资源文件
